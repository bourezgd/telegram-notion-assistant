# 🤖 مساعدي على تلغرام (فوق Notion)

> من إنجاز **ضياء الدين بورزق** · [@bourezgd](https://github.com/bourezgd)

بوت تلغرام شخصي يعمل فوق حسابك في **Notion**. يرسل لك مهامك ومواعيدك في وقتها بأزرار (✅ تم · ⏰ أجّلها · ❌ ألغها)، ويسجّل مصاريفك وعاداتك وصلاتك، ويجيب عن أسئلتك من بياناتك.

- **مجاني بالكامل:** يعمل على Cloudflare Workers (الخطة المجانية) + GitHub Actions + Notion.
- **بياناتك عندك:** كل شيء في حسابك على Notion، والصور (اختياريًا) في Google Drive الخاص بك.
- **بالعربية**، ويفهم الكتابة الحرّة والرسائل الصوتية (مع مفتاح Gemini المجاني).

> **الإعداد مرة واحدة يستغرق نحو 30 دقيقة.**
> 💡 **الأسهل:** افتح نسختك من المستودع في **Claude Code** واكتب «ابدأ الإعداد» (أو `/setup-assistant`). يجري معك السكيل مقابلة قصيرة — هل أنت متزوج؟ لديك أبناء؟ ما مصادر دخلك وفواتيرك؟ ما عاداتك؟ هل تريد تذكير الصلاة؟ — ثم يضبط الإعدادات، وينشئ قواعد Notion ويعبّئها ببياناتك، ويقودك حتى النشر.

## 🛠️ الإعداد (مرة واحدة)

ستحتاج حسابات مجانية في: **تلغرام**، **Notion**، **GitHub**، **Cloudflare**، واختياريًا **Google** (لمفتاح Gemini وصور Drive).

### 1) انسخ هذا المستودع
اضغط **Use this template ← Create a new repository** (اجعله **Private** لأن ملف الإعدادات سيحوي معلوماتك).

### 2) بوت تلغرام
1. في تلغرام افتح [@BotFather](https://t.me/BotFather) ← `/newbot` ← اختر اسمًا ← انسخ **التوكن** (`TELEGRAM_BOT_TOKEN`).
2. افتح [@userinfobot](https://t.me/userinfobot) ← انسخ رقم **Id** الخاص بك (`TELEGRAM_CHAT_ID`). البوت يرد عليك وحدك فقط.
3. افتح بوتك الجديد واضغط **Start** (مرة واحدة، ليُسمح له بمراسلتك).

### 3) Notion
1. أنشئ Integration: <https://www.notion.so/profile/integrations> ← **New integration** ← نوع Internal ← انسخ **Internal Integration Secret** (`NOTION_TOKEN`، يبدأ بـ `ntn_`).
2. أنشئ صفحة فارغة في Notion (مثل «🤖 مساعدي») ← **⋯ ← Connections ← اختر الـ Integration**.
3. عدّل قسم **👤 معلوماتك** في `wrangler.toml` (انظر الخطوة 5) — خصوصًا `FAMILY` و`CHILD_NAME` لأن خيارات «الشخص» في الملف الصحي تُبنى منهما.
4. أنشئ القواعد الاثنتي عشرة تلقائيًا (يحتاج Node.js 18+):
   ```bash
   git clone <رابط مستودعك> && cd <اسمه>
   NOTION_TOKEN=ntn_xxx node scripts/setup-notion.mjs "<رابط الصفحة من الخطوة 2>"
   git add wrangler.toml && git commit -m "Notion IDs" && git push
   ```
   يكتب السكربت معرّفات القواعد في `wrangler.toml`. إعادة تشغيله آمنة (يتخطّى ما أُنشئ).
5. اختياري: عبّئ بياناتك الأولية (الجهات، مصادر الدخل، الفواتير، العادات، المناسبات) من ملف JSON — الصيغة موثّقة أعلى `scripts/seed-notion.mjs`:
   ```bash
   NOTION_TOKEN=ntn_xxx node scripts/seed-notion.mjs setup/profile.json
   ```
   بلا حاسوب؟ شغّل نفس الأوامر من GitHub Codespaces (المستودع ← Code ← Codespaces) أو <https://shell.cloud.google.com>.

### 4) Cloudflare
1. أنشئ حسابًا: <https://dash.cloudflare.com/sign-up> ثم افتح **Workers & Pages** مرة واحدة (يفعّل رابط `workers.dev`؛ اختر أي اسم فرعي إن طُلب).
2. **Account ID** (`CLOUDFLARE_ACCOUNT_ID`): في صفحة Workers & Pages على اليمين، أو الرقم الطويل في رابط المتصفح.
3. **API Token** (`CLOUDFLARE_API_TOKEN`): الصورة الشخصية ← Profile ← API Tokens ← Create Token ← القالب **Edit Cloudflare Workers** ← Use template ← Continue to summary ← Create Token.

### 5) الإعدادات الشخصية — `wrangler.toml`
| المتغير | المعنى | مثال |
|---|---|---|
| `ABOUT_ME` | جملة عنك للمساعد | `"مصمم مستقل، متزوج"` |
| `FAMILY` | الأشخاص في الملف الصحي | `"أنا,الزوجة"` |
| `CHILD_NAME` · `CHILD_BIRTH` · `CHILD_SEX` | الطفل (فارغ = بلا ميزاته) | `"سارة"` · `"2025-03-14"` · `"girl"` أو `"boy"` |
| `COUNTRY` · `TZ_NAME` | البلد والمنطقة الزمنية | `"المغرب"` · `"Africa/Casablanca"` |
| `CITY_LAT` · `CITY_LNG` | موقع مدينتك لأوقات الصلاة | `"33.57"` · `"-7.59"` |
| `PRAYER_OFFSETS` | تعديل دقائق كل صلاة لمطابقة مسجدك | `"0,2,0,3,0"` |
| `WEEKEND_DAYS` | أيام العطلة (0 الأحد … 6 السبت) | `"5,6"` |
| `DISABLE` | إيقاف ميزات: `prayer` · `money` · `jihat` | `"prayer"` |
| `MORNING_TIME` وغيرها | أوقات الملخص والمراجعة والتقرير… | موثّقة داخل الملف |

> عمود المبلغ اسمه «المبلغ (دج)» والردود بالدينار، ويمكن استعماله بأي عملة.

### 6) أسرار GitHub
في مستودعك: **Settings ← Secrets and variables ← Actions ← New repository secret**:

| Name | القيمة |
|---|---|
| `CLOUDFLARE_API_TOKEN` | من الخطوة 4.3 |
| `CLOUDFLARE_ACCOUNT_ID` | من الخطوة 4.2 |
| `NOTION_TOKEN` | من الخطوة 3.1 |
| `TELEGRAM_BOT_TOKEN` | من الخطوة 2.1 |
| `TELEGRAM_CHAT_ID` | من الخطوة 2.2 |
| `GEMINI_API_KEY` | اختياري: <https://aistudio.google.com/apikey> (أو يُضاف لاحقًا من ⚙️ في البوت) |

### 7) النشر
**Actions ← نشر البوت على Cloudflare ← Run workflow**. عند ظهور ✅ أرسل `/start` لبوتك، ثم `/status` للتحقق من Notion وتلغرام وGemini. بعدها يُنشر تلقائيًا مع كل تعديل.

### 8) اختياري: صور الطفل في Google Drive
في البوت: **⚙️ ← 📸 ربط Google Drive** واتبع الخطوات (نسخ [`apps-script/drive.gs`](apps-script/drive.gs) إلى <https://script.google.com> ونشره Web app). الصور تبقى في حسابك.

## 🧭 الاستعمال اليومي
- **أزرار الشاشة:** 📋 اليوم · 📆 غدًا · 📊 الأسبوع · 💬 اسأل · ⚙️ · ➕ إضافة · 💸 إنفاق · 💵 قبض · 🔥 العادات · 📱 لوحتي.
- **اكتب مباشرة:** `مصروف 1500 بنزين` · `دخل 50000 راتب` · `نمو 8.4 70 44` (قياس الطفل) · أو سؤالًا: «ماذا عندي غدًا؟».
- **العادات:** 🔥 العادات ← ➕ عادة جديدة ← `شرب الماء كل ساعتين من 8 إلى 22` · `قراءة 21:00 وذكّرني بعد ساعة` · ✏️ للتعديل.
- **في Notion:** أي تعديل يُؤخذ به خلال دقيقة، ورسائل المهام المعدّلة تتحدّث وحدها.

## 📁 الملفات
- `src/`: الكود (ملف لكل ميزة؛ `worker.js` نقطة الدخول و`core.js` الإعدادات).
- `scripts/setup-notion.mjs`: إنشاء قواعد Notion · `scripts/seed-notion.mjs`: تعبئتها بالبيانات الأولية.
- `.claude/skills/setup-assistant/`: سكيل الإعداد بالمقابلة لـ Claude Code.
- `apps-script/drive.gs`: كود حفظ الصور في Google Drive.
- `test/`: اختبارات آلية (`npm test`) على Notion وتلغرام مزيّفين — لا يُنشر تعديل يفشل فيها.
- `wrangler.toml`: الإعدادات. `.github/workflows/deploy.yml`: الاختبارات ثم النشر وربط تلغرام.
